## 🎮 Game Modes & Arena Rules

* 🥊 **1 vs 1 Duel**: Head-to-head survival showdown.
* 👥 **4-Player Free For All**: Fast-paced survival race against 3 other runners.
* 👑 **8-Player Battle Royale**: The ultimate test of endurance for maximum leaderboard points.
* 🎯 **Practice Match**: Casual solo run to hone jump timings without affecting your stats.

### Arena Rules:
1. **Ghost Racing**: Opponents run alongside you as red ghosts—no physical collisions, pure obstacle skill.
2. **Sudden Death**: Colliding with any cactus or pterodactyl causes immediate elimination.
3. **Winner Takes All**: The last dinosaur running claims the victory and rating points.
